FINDING: app/db.py | `connect()` opens a brand-new SQLite connection on every single row fetch with no pooling or reuse, so a retrying/looping caller pays full connection setup per attempt.
FINDING: app/db.py | `sqlite3.connect(get("DB_PATH"))` will raise `TypeError` if `DB_PATH` is ever missing from `SETTINGS` (`get` returns `None`), instead of failing with a clear configuration error.
