Reviewing `app/serializers.py` against the models and repository it depends on.

**Primary defect:** `order_to_dict` reads `order.discount`, but `Order` (app/models.py:7) declares the field as `discount_percent`. Dataclasses don't define `__getattr__`, so every call raises `AttributeError: 'Order' object has no attribute 'discount'` — the function is unconditionally broken, not an edge case.
